Project Information

What is Oryn?

A lightweight, self-hosted web mail management platform designed to give organizations full ownership of their email.

🎯 Project Purpose & Motivation

• Centralized email providers (Google, Microsoft) are expensive and act as closed black boxes.

• Oryn provides an independent alternative: users can connect custom domains, create personalized mailboxes, compose emails, and manage inboxes from one intuitive dashboard.

• Academic Goal: Build a real, working web service while strictly following software engineering principles like MVC separation and standard REST conventions.

📁 Standard MVC Folders

• src/routes/: Defines URL paths and connects them to controller functions.

• src/controllers/: Reads req.body & req.params, handles errors, sends res.json().

• src/models/: Performs CRUD queries and encapsulates data records.

🧰 Dedicated Helpers Folder (src/helpers/)

• Specialized utilities (SMTP networking, DNS lookup, file storage) are kept out of controllers.

• Why? Prevents controller bloating and keeps the core assignment MVC code 100% textbook clean.

import { Router } from 'express';
import { EmailController } from '../controllers/email.controller.js';

const router = Router();

// Route definitions map HTTP verbs to controller methods
router.get('/', EmailController.getEmails);
router.get('/:id', EmailController.getEmailById);
router.post('/send', EmailController.sendEmail);
router.patch('/:id', EmailController.updateEmail);
router.delete('/:id', EmailController.deleteEmail);

export default router;
Controller & Model Deep Dive

Handling Requests & Managing Data

The controller orchestrates validation and response, while the model manages persistence.

Controller Logic (email.controller.js) 
static async sendEmail(req, res) {
  try {
    const { from, to, subject, text } = req.body;

    // 1. Input Validation
    if (!from || !to || !subject) {
      return res.status(400).json({ error: 'Missing required fields' });
    }

    // 2. Call Model to create record
    const newEmail = await EmailModel.create({
      from, to, subject, text, folder: 'sent'
    });

    // 3. Return HTTP 201 Created
    res.status(201).json({ success: true, email: newEmail });
  } catch (err) {
    res.status(500).json({ error: err.message });
  }
}
Model Layer (email.model.js) 
// backend/src/models/email.model.js
export class EmailModel {
  // Encapsulates file-based JSON or DB storage
  static async findAll(filter = {}) {
    const emails = await storage.readAll('emails');
    return emails.filter(e => (!filter.folder || e.folder === filter.folder));
  }

  static async create(data) {
    const record = { id: generateId(), ...data, createdAt: new Date() };
    await storage.insert('emails', record);
    return record;
  }
}
Client Integration

Frontend API Calling (React 19)

How our UI consumes backend endpoints via asynchronous fetch() requests.

React Component Calling Backend API 
// frontend/src/components/MailList.jsx
import { useState, useEffect } from 'react';

export function MailList({ currentFolder }) {
  const [emails, setEmails] = useState([]);
  const [loading, setLoading] = useState(true);

  // Call GET /api/emails on load
  useEffect(() => {
    async function fetchEmails() {
      try {
        const res = await fetch(`/api/emails?folder=${currentFolder}`);
        const data = await res.json();
        setEmails(data.emails || []);
      } finally {
        setLoading(false);
      }
    }
    fetchEmails();
  }, [currentFolder]);

  return <div>{emails.map(e => <MailItem key={e.id} email={e} />)}</div>;
}
1. Asynchronous Fetch & Promises
The frontend calls the backend REST routes using native fetch() wrapped in async/await for clean asynchronous flow.
2. State Synchronization
When an email is sent (POST /api/emails/send) or marked read (PATCH /api/emails/:id), React state immediately updates the DOM without full page reload.
3. Error & Loading Boundaries
Handles loading spinners during network requests and renders user-friendly toast messages if the backend returns 4xx or 5xx errors.
